# نظام إدارة المرضى (Next.js)

نسخة محسّنة من النظام القديم، مبنية على Next.js 15 + Supabase، مع تحديث لحظي (Realtime) لكل الجداول.

## المميزات الكاملة المُنقولة من النظام القديم

- **شاشة دخول** مع تسجيل دخول + إنشاء حساب جديد + استرجاع كلمة مرور
- **إدارة المرضى**: إضافة/تعديل/حذف + بحث + فلاتر متعددة (تشخيص، أمراض باطنية، فئة، هوية، كلوزابكس، باطنة، عمر)
- **نفقة الدولة**: عرض مجمّع بالفئة + ترتيب + بحث + نسخ الرقم القومي + طباعة A4
- **سجل الخروج**: عرض مع زر إرجاع للقسم
- **الإجازات**: عرض بطاقات أو جدول + تجميع بالأسبوع/الأسبوعين/عدد + تظليل "تجاوز إجازة"
- **مراجعة الباطنة**: ترتيب بأرقام المراجعة + أزرار تعديل
- **إحصائيات شاملة** + إحصائيات قسم 25 + الأرقام الناقصة
- **إدارة المستخدمين**: جدول صلاحيات كامل مع inline editing + Realtime
- **تغيير كلمة المرور** من داخل الشاشة
- **حساب مدير افتراضي**: `abomrzk@gmail.com` / `mm`

## التحديث اللحظي (Realtime) — الإضافة الجديدة

- **المرضى** (patients): أي تعديل/إضافة/حذف ينعكس فوراً على كل المتصلين
- **سجل الخروج** (exits): نفس الشيء
- **المستخدمين** (accounts): **تشيك بوكس واحد يتغير = كل الشاشات تحدث نفسها فوراً**

> لتشغيل Realtime على جدول accounts، شغّل ملف `supabase-migration.sql` في Supabase SQL Editor.

## خطوات النشر على Vercel

1. **إنشاء الجداول**: شغّل محتوى `supabase-migration.sql` في Supabase SQL Editor
2. **تفعيل Realtime**: 
   - Dashboard → Database → Replication
   - فعّل `patients` و `exits` و `accounts`
3. **إعداد Environment Variables** في Vercel:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_KEY`
4. **Deploy** على Vercel (اسحب المجلد أو اربط GitHub)
